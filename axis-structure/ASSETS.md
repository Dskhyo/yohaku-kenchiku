# 画像素材

内蔵 `image_gen.imagegen` で生成。CLI/APIキーは使用していません。素材はすべてテーマ内へコピーし、SharpでWebPに変換（quality 85）しています。参考画像そのものをサイト画像として貼り込んではいません。

保存先: `wp-content/themes/axis-structure/assets/images/`

Image is an asset, not a screenshot or a website design.

## office.webp / public.webp

既存プロジェクトの `assets/images/design.webp` と `assets/images/courtyard.webp` をコピー。既存画像を変更していません。元プロンプトは既存プロジェクトの `assets/images/PROMPTS.md` にあります。オフィスや公共施設の実写ではなく、空間を表す参考イメージとして使用しています。

グリッド・構造線・波形は編集可能なSVG/CSSです。構造模型、応力の色表示、波形はいずれも概念図であり、実際の構造解析結果ではありません。
